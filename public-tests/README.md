# Check público de Semana 02

Desde la raíz del proyecto: `bash public-tests/check.sh`. Comprueba los artefactos obligatorios de la Semana 02 y la estructura acumulativa del proyecto. No califica documentos ni sustituye una auditoría de seguridad.

Para prueba y build usen `npm run verify`; produce `reports/verification.json`. La calidad del contenido se revisa con la rúbrica.
